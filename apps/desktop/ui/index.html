FPS desktop shell

This window is a native Tauri 2 shell, not a wrapper around a remote website. The product UI is the shared panel in apps/web.

Start the control plane on 127.0.0.1:47890, build the shared UI with pnpm --filter @fps/web build, then run cargo tauri dev from apps/desktop/src-tauri. Session tokens belong in the OS vault (file fallback is documented in vault.rs).

If you opened this fallback page, apps/web/dist was not bundled into the app. That is expected on this source tree before an operator desktop build (milestone 0.0.1-alpha.5).
