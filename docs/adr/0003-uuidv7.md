# ADR 0003 — UUIDv7 identifiers

- Status: accepted
- Date: 2026-09-01

## Decision

All durable identifiers are UUIDv7 stored as canonical 36-character text.

## Why

Sortable, time-ordered, standard, and avoids ULID/UUID split across languages.

## Alternatives rejected

- ULID: excellent, but UUID is more widely typed in OpenAPI/TS.
- Auto-increment integers: leak occupancy and couple tenants.
